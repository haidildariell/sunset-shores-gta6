SUNSET SHORES — an open-world crime game in Palmera Bay, in the spirit of GTA 6. Play Dario "Daz" Cole, a delivery driver pulled into Mara Quinn's crew: drive, fight, and run 9 story missions across the city — from courier jobs and police chases to the Sunset Showdown finale against boss Rook at the Palmera Bowl. Top-down 2D canvas game, no libraries, with day/night, radio stations, traffic, a casino landmark, and a wanted system.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
